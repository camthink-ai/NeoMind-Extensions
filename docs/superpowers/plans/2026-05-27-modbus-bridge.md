# Modbus Bridge Extension Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a NeoMind extension that bridges Modbus TCP/RTU devices into NeoMind's device system with auto-registration and real-time metrics.

**Architecture:** Sync Modbus client (tokio-modbus tcp-sync/rtu-sync features) polled from std::thread. Device state stored in `RwLock<HashMap>`. Register maps configured per-device. Metrics exported via `produce_metrics()`. No Tokio runtime needed.

**Tech Stack:** Rust, tokio-modbus 0.17 (sync), neomind-extension-sdk 0.6.3, React 18 + Vite (frontend)

**Spec:** `docs/superpowers/specs/2026-05-27-device-ecosystem-extensions-design.md` Section 1

```rust
use crate::types::{RegisterConfig, RegisterDataType, RegisterValue};

/// Decode raw register words into a RegisterValue
pub fn decode_register(config: &RegisterConfig, words: &[u16]) -> RegisterValue {
    let raw_value = match config.data_type {
        RegisterDataType::Uint16 => words.get(0).copied().unwrap_or(0) as f64,
        RegisterDataType::Int16 => {
            let v = words.get(0).copied().unwrap_or(0) as i16;
            v as f64
        }
        RegisterDataType::Uint32 => {
            let hi = words.get(0).copied().unwrap_or(0) as u32;
            let lo = words.get(1).copied().unwrap_or(0) as u32;
            ((hi << 16) | lo) as f64
        }
        RegisterDataType::Int32 => {
            let hi = words.get(0).copied().unwrap_or(0) as u32;
            let lo = words.get(1).copied().unwrap_or(0) as u32;
            ((hi << 16) | lo) as i32 as f64
        }
        RegisterDataType::Float32 => {
            let hi = words.get(0).copied().unwrap_or(0) as u32;
            let lo = words.get(1).copied().unwrap_or(0) as u32;
            let bits = (hi << 16) | lo;
            f32::from_bits(bits) as f64
        }
        RegisterDataType::Bool => {
            words.get(0).copied().unwrap_or(0) != 0
        } as f64,
    };

    let value = if config.scale != 0.0 {
        raw_value * config.scale
    } else {
        raw_value
    };

    RegisterValue {
        name: config.name.clone(),
        value,
        unit: config.unit.clone(),
        raw: words.to_vec(),
    }
}
```

```rust
use crate::register_map::decode_register;
use crate::types::{ConnectionMode, DeviceConfig, DeviceState, RegisterValue};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};
use tokio_modbus::prelude::*;

/// Holds a connection and manages polling for a single Modbus device
pub struct ModbusDevice {
    config: DeviceConfig,
    state: Arc<Mutex<DeviceState>>,
    running: Arc<std::sync::atomic::AtomicBool>,
    thread_handle: Option<std::thread::JoinHandle<()>>,
}

impl ModbusDevice {
    pub fn new(config: DeviceConfig) -> Self {
        let state = Arc::new(Mutex::new(DeviceState {
            register_values: vec![],
            connected: false,
            poll_errors: 0,
            last_poll_ms: 0,
            config: config.clone(),
        }));
        Self {
            config,
            state,
            running: Arc::new(std::sync::atomic::AtomicBool::new(false)),
            thread_handle: None,
        }
    }

    /// Start the polling loop in a background thread
    pub fn start(&mut self) -> Result<(), String> {
        if self.running.load(std::sync::atomic::Ordering::SeqCst) {
            return Err("Already running".into());
        }
        self.running.store(true, std::sync::atomic::Ordering::SeqCst);

        let config = self.config.clone();
        let state = self.state.clone();
        let running = self.running.clone();

        let handle = std::thread::Builder::new()
            .name(format!("modbus-{}", config.device_id))
            .spawn(move || {
                polling_loop(config, state, running);
            })
            .map_err(|e| format!("Thread spawn error: {}", e))?;

        self.thread_handle = Some(handle);
        Ok(())
    }

    /// Stop the polling loop
    pub fn stop(&mut self) {
        self.running.store(false, std::sync::atomic::Ordering::SeqCst);
        if let Some(handle) = self.thread_handle.take() {
            let _ = handle.join();
        }
    }

    pub fn get_state(&self) -> DeviceState {
        self.state.lock().unwrap().clone()
    }

    pub fn update_poll_interval(&mut self, interval_ms: u64) {
        self.config.poll_interval_ms = interval_ms;
        if let Ok(mut s) = self.state.lock() {
            s.config.poll_interval_ms = interval_ms;
        }
    }

    /// Read registers immediately (one-shot, outside polling loop)
    pub fn read_registers(&self, start: u16, count: u16) -> Result<Vec<u16>, String> {
        let mut ctx = connect_sync(&self.config)?;
        ctx.read_holding_registers(start, count)
            .map_err(|e| format!("Read error: {}", e))
    }

    /// Write a single holding register
    pub fn write_register(&self, address: u16, value: u16) -> Result<(), String> {
        let mut ctx = connect_sync(&self.config)?;
        ctx.write_single_register(address, value)
            .map_err(|e| format!("Write error: {}", e))
    }

    /// Write a single coil
    pub fn write_coil(&self, address: u16, value: bool) -> Result<(), String> {
        let mut ctx = connect_sync(&self.config)?;
        ctx.write_single_coil(address, value)
            .map_err(|e| format!("Write coil error: {}", e))
    }
}

/// Create a sync Modbus context (connection)
fn connect_sync(config: &DeviceConfig) -> Result<sync::Context, String> {
    match config.mode {
        ConnectionMode::Tcp => {
            let ip = config.ip.as_deref().ok_or("Missing IP address")?;
            let port = config.port.unwrap_or(502);
            let socket_addr = format!("{}:{}", ip, port)
                .parse()
                .map_err(|e| format!("Invalid address: {}", e))?;
            // Connect to specific slave through TCP
            sync::tcp::connect_slave(socket_addr, Slave(config.slave_id))
                .map_err(|e| format!("TCP connect error: {}", e))
        }
        ConnectionMode::Rtu => {
            let serial = config.serial_port.as_deref().ok_or("Missing serial port")?;
            let baud = config.baud_rate.unwrap_or(9600);
            let builder = tokio_serial::new(serial, baud);
            sync::rtu::connect_slave(&builder, Slave(config.slave_id))
                .map_err(|e| format!("RTU connect error: {}", e))
        }
    }
}

fn polling_loop(
    config: DeviceConfig,
    state: Arc<Mutex<DeviceState>>,
    running: Arc<std::sync::atomic::AtomicBool>,
) {
    while running.load(std::sync::atomic::Ordering::SeqCst) {
        let interval = {
            let s = state.lock().unwrap();
            s.config.poll_interval_ms
        };

        let start = Instant::now();

        // Poll all registers
        match poll_all_registers(&config) {
            Ok(values) => {
                let elapsed = start.elapsed().as_millis() as u64;
                let mut s = state.lock().unwrap();
                s.register_values = values;
                s.connected = true;
                s.poll_errors = 0;
                s.last_poll_ms = elapsed;
            }
            Err(_) => {
                let mut s = state.lock().unwrap();
                s.connected = false;
                s.poll_errors += 1;
            }
        }

        // Sleep for remaining interval
        let elapsed = start.elapsed().as_millis() as u64;
        let sleep_ms = if interval > elapsed { interval - elapsed } else { 100 };
        if running.load(std::sync::atomic::Ordering::SeqCst) {
            std::thread::sleep(Duration::from_millis(sleep_ms));
        }
    }
}

fn poll_all_registers(config: &DeviceConfig) -> Result<Vec<RegisterValue>, String> {
    let mut client = connect_sync(config)?;
    let mut values = Vec::new();

    for reg in &config.registers {
        let words = client
            .read_holding_registers(reg.address, reg.count)
            .map_err(|e| format!("Read register {} error: {}", reg.name, e))?;
        values.push(decode_register(reg, &words));
    }

    Ok(values)
}
```

```rust
pub struct ModbusBridgeExtension {
    devices: RwLock<HashMap<String, ModbusDevice>>,
    total_commands: AtomicI64,
}

impl ModbusBridgeExtension {
    pub fn new() -> Self {
        Self {
            devices: RwLock::new(HashMap::new()),
            total_commands: AtomicI64::new(0),
        }
    }

    fn add_device(&self, config: DeviceConfig) -> Result<serde_json::Value> {
        let device_id = config.device_id.clone();
        let mut device = ModbusDevice::new(config);

        // Test connection first
        let test_result = device.read_registers(0, 1);
        let initial_connected = test_result.is_ok();

        device.start().map_err(|e| ExtensionError::ExecutionFailed(e))?;

        let mut devices = self.devices.write().unwrap();
        // Stop old device if replacing
        if let Some(mut old) = devices.remove(&device_id) {
            old.stop();
        }
        devices.insert(device_id.clone(), device);

        Ok(json!({
            "success": true,
            "device_id": device_id,
            "connected": initial_connected
        }))
    }

    fn remove_device(&self, device_id: &str) -> Result<serde_json::Value> {
        let mut devices = self.devices.write().unwrap();
        if let Some(mut device) = devices.remove(device_id) {
            device.stop();
            Ok(json!({"success": true, "device_id": device_id}))
        } else {
            Err(ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))
        }
    }

    fn read_registers(&self, device_id: &str, start: u16, count: u16) -> Result<serde_json::Value> {
        let devices = self.devices.read().unwrap();
        let device = devices.get(device_id)
            .ok_or_else(|| ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))?;
        let words = device.read_registers(start, count)
            .map_err(|e| ExtensionError::ExecutionFailed(e))?;
        Ok(json!({"success": true, "registers": words}))
    }

    fn write_register(&self, device_id: &str, address: u16, value: u16) -> Result<serde_json::Value> {
        let devices = self.devices.read().unwrap();
        let device = devices.get(device_id)
            .ok_or_else(|| ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))?;
        device.write_register(address, value)
            .map_err(|e| ExtensionError::ExecutionFailed(e))?;
        Ok(json!({"success": true}))
    }

    fn write_coil(&self, device_id: &str, address: u16, value: bool) -> Result<serde_json::Value> {
        let devices = self.devices.read().unwrap();
        let device = devices.get(device_id)
            .ok_or_else(|| ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))?;
        device.write_coil(address, value)
            .map_err(|e| ExtensionError::ExecutionFailed(e))?;
        Ok(json!({"success": true}))
    }

    fn list_devices(&self) -> Result<serde_json::Value> {
        let devices = self.devices.read().unwrap();
        let list: Vec<serde_json::Value> = devices.iter().map(|(id, dev)| {
            let state = dev.get_state();
            json!({
                "device_id": id,
                "connected": state.connected,
                "register_count": state.register_values.len(),
                "poll_errors": state.poll_errors,
                "last_poll_ms": state.last_poll_ms,
            })
        }).collect();
        Ok(json!({"devices": list}))
    }

    fn update_polling(&self, device_id: &str, interval_ms: u64) -> Result<serde_json::Value> {
        let mut devices = self.devices.write().unwrap();
        let device = devices.get_mut(device_id)
            .ok_or_else(|| ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))?;
        device.update_poll_interval(interval_ms);
        Ok(json!({"success": true}))
    }

    fn set_register_map(&self, device_id: &str, registers: Vec<types::RegisterConfig>) -> Result<serde_json::Value> {
        // Stop old, create new device with updated register map
        let mut devices = self.devices.write().unwrap();
        if let Some(mut old) = devices.remove(device_id) {
            let mut config = old.get_state().config.clone();
            old.stop();
            config.registers = registers;
            let mut new_device = ModbusDevice::new(config);
            let _ = new_device.start();
            devices.insert(device_id.to_string(), new_device);
            Ok(json!({"success": true}))
        } else {
            Err(ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))
        }
    }

    fn get_device_data(&self, device_id: &str) -> Result<serde_json::Value> {
        let devices = self.devices.read().unwrap();
        let device = devices.get(device_id)
            .ok_or_else(|| ExtensionError::ExecutionFailed(format!("Device not found: {}", device_id)))?;
        let state = device.get_state();
        Ok(json!({
            "device_id": device_id,
            "connected": state.connected,
            "registers": state.register_values,
            "poll_errors": state.poll_errors,
            "last_poll_ms": state.last_poll_ms,
        }))
    }
}

    async fn execute_command(&self, command: &str, args: &serde_json::Value) -> Result<serde_json::Value> {
        self.total_commands.fetch_add(1, Ordering::SeqCst);

        match command {
            "add_device" => {
                let config: DeviceConfig = serde_json::from_value(args.clone())
                    .map_err(|e| ExtensionError::InvalidArguments(format!("Invalid device config: {}", e)))?;
                self.add_device(config)
            }
            "remove_device" => {
                let device_id = args.get("device_id")
                    .and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                self.remove_device(device_id)
            }
            "list_devices" => self.list_devices(),
            "get_device_data" => {
                let device_id = args.get("device_id")
                    .and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                self.get_device_data(device_id)
            }
            "read_registers" => {
                let device_id = args.get("device_id").and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                let start = args.get("start").and_then(|v| v.as_u64()).unwrap_or(0) as u16;
                let count = args.get("count").and_then(|v| v.as_u64()).unwrap_or(1) as u16;
                self.read_registers(device_id, start, count)
            }
            "write_register" => {
                let device_id = args.get("device_id").and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                let address = args.get("address").and_then(|v| v.as_u64()).unwrap_or(0) as u16;
                let value = args.get("value").and_then(|v| v.as_u64()).unwrap_or(0) as u16;
                self.write_register(device_id, address, value)
            }
            "write_coil" => {
                let device_id = args.get("device_id").and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                let address = args.get("address").and_then(|v| v.as_u64()).unwrap_or(0) as u16;
                let value = args.get("value").and_then(|v| v.as_bool()).unwrap_or(false);
                self.write_coil(device_id, address, value)
            }
            "update_polling" => {
                let device_id = args.get("device_id").and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                let interval = args.get("interval_ms").and_then(|v| v.as_u64()).unwrap_or(5000);
                self.update_polling(device_id, interval)
            }
            "set_register_map" => {
                let device_id = args.get("device_id").and_then(|v| v.as_str())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing device_id".into()))?;
                let registers: Vec<types::RegisterConfig> = args.get("registers")
                    .and_then(|v| serde_json::from_value(v.clone()).ok())
                    .ok_or_else(|| ExtensionError::InvalidArguments("Missing or invalid registers".into()))?;
                self.set_register_map(device_id, registers)
            }
            "configure" => Ok(json!({"status": "ok"})),
            _ => Err(ExtensionError::CommandNotFound(command.to_string())),
        }
    }

    fn produce_metrics(&self) -> Result<Vec<ExtensionMetricValue>> {
        let now = chrono::Utc::now().timestamp_millis();
        let mut metrics = Vec::new();

        metrics.push(ExtensionMetricValue {
            name: "total_commands".into(),
            value: ParamMetricValue::Integer(self.total_commands.load(Ordering::SeqCst)),
            timestamp: now,
        });

        let devices = self.devices.read().unwrap();
        for (device_id, device) in devices.iter() {
            let state = device.get_state();

            metrics.push(ExtensionMetricValue {
                name: format!("modbus.{}.connection", device_id),
                value: ParamMetricValue::String(if state.connected { "connected".into() } else { "disconnected".into() }),
                timestamp: now,
            });

            metrics.push(ExtensionMetricValue {
                name: format!("modbus.{}.poll_errors", device_id),
                value: ParamMetricValue::Integer(state.poll_errors as i64),
                timestamp: now,
            });

            for rv in &state.register_values {
                metrics.push(ExtensionMetricValue {
                    name: format!("modbus.{}.{}", device_id, rv.name),
                    value: ParamMetricValue::Float(rv.value),
                    timestamp: now,
                });
            }
        }

        Ok(metrics)
    }

    async fn configure(&mut self, config: &serde_json::Value) -> Result<()> {
        // Accept config silently
        let _ = config;
        Ok(())
    }

    fn as_any(&self) -> &dyn std::any::Any {
        self
    }
}
```

## Notes for Implementation

1. **tokio-modbus sync API**: The `tcp-sync` and `rtu-sync` features provide `sync_connect()` methods that return sync clients. These don't need a Tokio runtime — perfect for cdylib extensions.

2. **Thread safety**: `ModbusDevice` uses `Arc<Mutex<DeviceState>>` for the polling thread to share state. The `devices` HashMap uses `RwLock` per NeoMind conventions.

3. **Device lifecycle**: `add_device` starts a polling thread. `remove_device` stops it. `set_register_map` stops old device and creates a new one with updated config.

4. **No external runtime deps**: Everything is sync or std::thread based. No conflict with NeoMind's Tokio runtime.
